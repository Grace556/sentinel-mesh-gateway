# Changelog

All notable changes to Sentinel Mesh Gateway are documented in this file.

## [1.0.0] - 2026-09-08
### Added
- Modular Request/Response routing engine with trace propagation.
- Token Bucket rate limiter with per-client identity tracking.
- Circuit breaker state machine (Closed, Open, Half-Open).
- Distributed telemetry logger with queryable trace storage.
- Comprehensive domain error model hierarchy.
- Automated GitHub Actions CI workflow with Dependabot configuration.
